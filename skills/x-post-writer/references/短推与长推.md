# 模式、结构与长度

## 输入与篇幅

优先采用用户指定的读者、目的、语气、字数与素材。默认用第一人称；已要求亲历式时直接以素材中的处境和行动起稿。只有题目时可写“我的判断 / 我会怎么做”，不能空造结果来充当亲历。素材很少，长推也可以较短。

未指定长度时，中文短推通常先写约60—100字；长推可从约600—1200字起稿。这是编辑参考，不是平台限额，也不是越接近上限越好，不硬凑字数。

## 短推：一条交付一件事

开头进入读者处境，后面给实质内容，结尾形成清楚收获。可以是一两句话或几个短段，不必每次用同一结构。

- **观点与理由**：一个判断，加具体理由或例子；反差须由素材支持。
- **问题与小方法**：一个真实卡点，给足够执行的动作。
- **场景与感受**：说出读者认得的处境，给观察或理解。
- **短案例与判断**：用一处细节支撑不过度扩大的结论。
- **视频配文**：补足观看动机或关注点，不重复可见过程。

独立短推应有自己的价值，不能只留下“后面有答案”。视频配文可以依赖视频，但感受和承诺须与真实画面相符。“最强、所有人、唯一、翻倍”等没有证据就不保留。

几版短推先换入口：实用、身份认同、共鸣、具体问题或有依据的反差，而不只换词。推荐依据是读者与账号方向，不能用预计流量代替。

## 开头怎样有吸引力

从素材选适合的入口，按[开头—结构—兑现位置](观点与结构.md#开头结构兑现位置)配对，不轮流套模板。每次先从材料选入口，再写一句开头和一句答案，核对两者确实对应。默认几版短推使用不同入口，不让所有稿子都以问句或“我发现”开头。

没结果数据时，换卡点、细节或方法开头。开头有力度来自准确和具体，不靠“震惊、颠覆、彻底、全网唯一”或虚构紧迫性。

悬念只延迟解释，不隐瞒必要条件、不冒造秘密。自然设问可以用，问题须与正文有关；“同意扣1”“评论领答案”“转发解锁”“不看就亏”不作默认开头或结尾。是否触及平台要求见[X创作者规范](X创作者规范.md)。

## 长推：兑现阅读投入

先确定中心判断和能交付的收获，再组织内容：

| 素材 | 组织重点 | 开头承诺 |
| --- | --- | --- |
| 教程/实操 | 任务、起点、步骤、检查点、卡点 | 跟着完成一个具体任务 |
| 观点/判断 | 主张、理由、例子、反例或边界 | 获得可解释的判断方法 |
| 真实经历 | 处境、选择、尝试、结果与反思 | 看清可迁移的经验 |
| 案例/资料整合 | 归属、差异、共同点和可学方法 | 理解案例怎样支持结论 |

短段、具体小标题与适量列表服务理解；不每句单独分段，也不把整套步骤堆成长段。需要截图时只建议图位和应显示的内容，不编造截图或没看过的操作界面。

亲历式长推围绕“我遇到什么 → 我怎样选择和做 → 哪个细节改变了判断 → 我留下什么做法”推进，素材不需要的环节直接省略。少写泛指“创作者应当”，让行动有明确主体；对读者的具体建议仍可正常使用“你”。

写完核对开头：承诺的方法、案例、步骤是否存在，结果是否保留条件。不能兑现就改开头，不追加虚构证据。

需要起稿骨架时，可用“具体处境 → 核心判断 → 案例或步骤 → 适用边界 → 可开始的动作”，但只保留材料需要的部分；不能让每篇长推都长得一样。

结尾可给一个能开始的动作、仍值得思考的问题，或自然回到主题。只有用户提供了真实账号介绍、产品或链接时，才按其用途设计尾注或承接；不擅加私域、二维码、收费和关注口令。

## 推文串与长推拆短

用户明确说thread、串或接龙时，按共同主题推进，每条讲清小结论，编号只帮助顺序。第一条交代读者收益，后续逐步兑现，不让每条重复开头或只吊胃口。每条检查长度和完整性；移动完整例子，不从句中截断。

普通“长推”不自动等于thread。权限未知先交付完整长稿；用户说明无法发长帖或想做串时再改。

长推拆短时，提取方法、踩坑、观点、对照或案例，补足理解所需背景，保留限定、来源和数据口径。各条都成立且有不同入口；原稿位置留在策划说明，不进正文。

## 平台计数与权限

核对记录：2026-11-09，X帮助中心列出普通帖上限为280字符，并区分有账号权限要求的长帖。不要把记录当永久账户能力。

- [X：帖子类型](https://help.x.com/en/using-x/types-of-posts)
- [X：如何发帖](https://help.x.com/en/using-x/how-to-post)
- [X：字符计数](https://docs.x.com/fundamentals/counting-characters)

用户给严格限额时，用当前可用的官方计数工具或已安装、适用的计数实现。中文、emoji、网址与混排不能简单用肉眼字数代替。缺少可靠工具时给紧凑稿、留余量，不输出未经计算的“精确280字符内”，也不自动安装工具或登录。用户要求精确保证却无法核验时，说明仍需平台计数器确认，同时提供草稿。
