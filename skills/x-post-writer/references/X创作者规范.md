# X创作者规范检查

查阅日期：2026-11-09。这里是写稿检查，不是平台审核结论。用户要求“符合创作者计划”时先分清一般内容规则与具体收益计划；不能仅凭文案保证账号准入、曝光或收入。

## 写稿时怎样执行

1. **原创贡献**：对PPT/文字稿加入作者自己的取舍、解释、比较、步骤或判断。授权把材料写成“我”不等于获得版权或收益原创认定；不要只换代词和词语。
2. **开头与兑现**：悬念围绕真实内容，本条或实际搭配的视频给答案；不伪装新闻、成绩、秘密或截止时间。研究对标用于学表达，不能搬走别人作品冒认。
3. **互动**：不生成互赞、互关、刷量、付费换互动或“赞够公布”等话术。与内容相关的自然问题可以保留，但不把每条结尾都写成索要互动。多版候选供选稿，不默认批量发相似版本。
4. **动机使用**：愤怒针对问题，避免辱骂和造谣；嫉妒、贪婪不编收益与排名；色欲不转为无关性刺激或低俗内容。七宗罪为策划角度，不能抵消平台规则。
5. **发布前资格边界**：本技能是辅助起草，须由创作者实质创作、审阅并决定如何使用；这一步也不保证通过平台判定。对自动化创作的限制不能靠去AI味、伪称亲历、人工点击发布或轻微改词来绕过。不提供自动发布或隐藏生成来源的操作。
6. **生成媒体**：涉及AI生成的武装冲突影像时，官方变现规范要求清楚披露；逼真的游戏冲突影像也有合成标记要求。按具体题材核对，不错误扩展为“所有AI辅助文字一律要求同一标记”，也不宣称AI辅助内容一律可变现。

## 交付边界

未查账号与平台审核结果时，只能报告本稿做过哪些内容检查。出现不可采用的成绩、经历或违规诱导时，直接修成有依据、有价值的文案；不把“待核实”等编辑工作标签放进公开正文。用户询问收益资格时，说明当前官方要求与尚未验证之处。
