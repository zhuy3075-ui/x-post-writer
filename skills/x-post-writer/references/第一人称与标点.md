# 第一人称亲历式成稿与标点

有用户样文或文风档案时，按[个人文风](个人文风.md)采用同体裁证据；当前明确要求优先。下面是默认写作偏好，不是已经从用户作品测得的个人文风。

## 叙事口吻

默认像作者在讲自己的观察、动作和反思。用户明确要求“直接写成亲历”，就将所给素材里已有的处境、做法和转折转为“我”的叙事，不退回整篇课堂摘要，也不再次询问同一授权。

内部区分四种依据：用户明确的本人经历；用户授权把分享作亲历式改写；作者对材料的判断；保留归属的外部事实和引语。授权改写可以改变叙述视角，不能自动证明事情确由账号本人完成，也不能用来保证原创收益资格。

- **行动有主体**：把“应研究对标”落成“我看对标时，会先拆它的开头和正文怎样对应”。
- **亲历有过程**：在已有素材中选一个处境、一个动作、一处转折；不另外编出深夜、咖啡、朋友对话来装真实。
- **范围不扩张**：不补造具体日期、客户、任职、资质、截图、收益或涨粉；不把他人的独有成绩据为己有。用户要求虚构作品时，按其明确的虚构用途另行写作。
- **不过度加“我”**：叙述者清楚即可；允许省略主语、直接设问和对读者说“你”，不要求每句以“我”开头。
- **保持引语原义**：别人说的话保留说话者。把引语改为自己的表达时去掉原话引号，不能把转述冒充逐字引用。
- **只有方法没有经历**：用“我会先…”呈现作者的做法或选择；不把尚未执行的建议强写成已经取得结果。

用户未授权将他人经历转成自己的事实陈述时，采用自己的判断或行动建议。用户明确授权亲历式改写后，不必在每条正文中加工作标签；来源底稿保留，必须的事实归属仍不能抹去。

## 标点服务含义和阅读节奏

默认采用中文标点，技术名称、网址、代码沿用其必要形式。先朗读整句，再决定停顿；不按每句字数或标点配额排版。

| 标点 | 什么时候用 | 需要避免 |
| --- | --- | --- |
| ，。 | 句内关系清楚、一个意思说完 | 一逗到底；用换行代替全部句号 |
| ？ | 真正的问题、值得回答的悬念 | 连续问号、没有回答的假问题 |
| ：、 | 展开具体内容、并列短项 | 每段都“核心是：”；为了去AI味删掉正常列举 |
| ； | 同一句中较复杂的并列关系 | 为显正式堆分号，或一概禁用 |
| “”（） | 有依据的原话、术语边界、必要补充 | 给普通词层层套引号；把主要结论藏在括号中 |
| —— | 补充、转折或语义上的延展 | 句句用破折号；没有语义需要的长横线 |
| ……、！ | 语境确实需要的未尽或强情绪 | 每段省略号、叠加感叹号、强行煽情 |

不强制使用表内所有标点。检查引号和括号配对、问句与问号匹配、顿号是否连接同层级项目、句号后是否仍有同句残片。首尾多余标点和不必要重复应调整；技术表达与来源引语不盲改。

分段按意思推进。长推可有小标题和列表；短推只需读者一眼看清。不要每四五个字换一行，不制造孤立标点或为“人味”故意断句。
