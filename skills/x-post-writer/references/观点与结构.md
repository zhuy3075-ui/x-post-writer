# 从材料到观点，再到开头与正文

生成和实质改稿时使用。只做标点修正或只检测时，不另换观点。底稿默认留在正文之外；一条很短的稿可在内部用几句话完成，不必交付整张表。

## 观点卡：先判断有什么值得说

先分清素材中的观点、动作、案例、数据；每个可用信息保留材料ID和段落、时间或页码。照片中的成绩属于原案例，不能转为作者成绩；听不清或口径不明的信息不进成稿。

材料有多个入口时，比较少量不同观点，通常2—4个；单一事实只支持一个观点时不凑数量。每张卡写：

| 字段 | 填什么 |
| --- | --- |
| 判断 | 一句能被解释或质疑的主张，不能只写“AI写作”这类话题名 |
| 依据 | 材料ID、位置及实际支持的动作、细节或判断；区分事实与编辑推断 |
| 读者收益 | 哪个读者能据此做什么、判断什么或理解什么 |
| 条件与边界 | 结论在哪里成立，有什么不能推出，缺哪一环就缩小承诺 |

先选依据够用、价值清楚、适合账号方向的观点。反常识、成本、用户卡点、利益或后果可以帮助发现角度，但不用全部套一遍，也不把推测变成事实。七宗罪在选中观点后辅助表达，不代替依据。

例如，PPT第8页支持“刚弄懂的问题也能成为选题”：新手仍记得卡点，这是可迁移的理由。它不支持“新手教程必然比专家教程流量高”。可写自己怎样整理卡点，不能补出涨粉结果。

多条短推各自交付不同收益，例如找问题、写截图说明、检查标题承诺；“省时间、提高效率、少走弯路”若依据和动作相同，就只是同一观点的改词。

## 开头—结构—兑现位置

选开头前先写出答案，再核对下表。每条内部记录“开头承诺 → 采用结构 → 答案位置 → 来源”。只交付能兑现的版本，不要求每次生成所有类型。

| 开头入口 | 必需素材 | 短推怎样接 | 完整长推怎样接 | 兑现位置 |
| --- | --- | --- | --- | --- |
| 具体悬念 | 确有一个值得解释的选择或细节 | 紧接关键答案及用法 | 先揭示判断，再展开理由或方法 | 答案尽早出现；后文补足过程，不拖到文末才揭词 |
| 卡点或场景 | 有实际卡点、行动或已授权的叙事材料 | 卡在哪里、我怎么改 | 任务起点、关键动作、检查点及条件 | 一处明确动作与可识别的完成标准 |
| 清楚收获 | 有足够步骤或判断依据 | 给出完整小方法 | 承诺的任务、步骤、示例与卡点 | 每项承诺在正文有对应内容 |
| 有依据的反差 | 有可比较的两种做法或结果 | 说清差异及理由 | 共同条件、差异、解释、适用边界 | 真实对照，不能从差异直接宣布因果 |
| 亲历转折 | 素材有处境、选择和改变判断的细节 | 一次选择加一条反思 | 处境、尝试、关键选择、实际结果或当前做法 | 转折有材料依据；没结果就止于做法，不虚构成功 |
| 案例或结果 | 有可采用结果、口径及归属 | 结果加限制或一个可学动作 | 案例背景、证据、机制解释、边界 | 说明结果属于谁、能学什么，不只亮数字 |
| 画面感受 | 已读图视频或明确描述 | 补观看理由、关注点或感受 | 按任务选择案例结构 | 视频确能兑现；说明中不声称看过未读取的文件 |

开头写成“我写教程前先准备三样材料”，正文就必须给出三样及其用途；若只有两样材料，改承诺，不补第三样凑数。好奇只推迟解释，不故意遗漏必要条件。

## 短长与推文串各自成形

- **短推**：一个观点，紧接足够的理由或动作；独立稿本条给答案，配文可由实际视频兑现。不拿长推第一段当独立短推。
- **完整长推**：教程从具体任务走到完成；判断稿从主张走到证据与边界；经历稿从处境走到选择和反思。只用材料需要的环节，不强补冲突、对话或结局。
- **推文串**：仅在用户明确要求时使用。第一条给总承诺，每条新增一个完整的小结论，末条自然收束；不能把普通“长推”自动拆成编号接龙。

拆长为短时，把一个信息重新组织成“最少背景＋判断/动作＋必要条件”。比较型短推保留双方和比较条件；技巧型短推给足可执行步骤，不只裁掉后半段。

## 配对失败时怎样改

先改大于材料的开头，再补材料已有但正文遗漏的信息；没有依据的结果不补写。正文若只是反复说观点重要，按[段落推进检查](评审与示例.md#段落推进检查)合并或删减。格式、长度见[短推与长推](短推与长推.md)。
