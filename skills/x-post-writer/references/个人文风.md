# 用作者样文建立可核对的文风

用户提供自己的作品、已有档案，或明确要求学习文风时使用。无样文时直接沿用用户已确定的第一人称、亲历叙述、自然标点等偏好；这不等于已经识别出个人文风。

## 先认样文，再归纳习惯

- 优先读用户明确指出是自己写的完整作品或经其确认代表自己文风的定稿；记录样文ID、体裁、时间（已知时）、主题与原文件位置。
- 参考作者的作品、会议PPT、录音清洗稿、AI初稿不是用户文风证据。用户明确要求模仿另一作者时，另建“参考风格”，不混为个人档案。
- 短推、长推、推文串分组观察；不同主题、不同阶段的差异先保留，不把一篇特殊风格泛化成所有文章。
- 样文少仍可起稿，把观察标为暂定，记录反例。没有样文就不编常用词、平均句长和标点比例，不承诺像本人。

无需为了达到文章数量门槛停工或自动采集账号。少量样文适合本次局部参考；只有跨作品重复出现的做法才适合写成稳定习惯。长文风格需要长文证据，几十条短推不能直接替代。

## 档案要保存证据

按[个人文风档案模板](../assets/个人文风档案模板.md)组织，有已有档案就沿用其格式。每条观察带样文ID、具体位置、适用体裁及反例，证据不足写暂定，不用主观匹配百分比。

| 观察层 | 要识别的内容 | 避免的误用 |
| --- | --- | --- |
| 语言和标点 | 常用称呼、词语、问句、逗号/冒号/破折号的实际用途 | 把出现次数直接变成配额或禁令 |
| 节奏和结构 | 开头进入方式、段落长度、怎样转折与收束 | 所有稿套同一结构，机械交替长短句 |
| 选题和读者 | 常写的任务、观察对象、解释深度 | 把过去主题当作不能跨越的边界 |
| 证据习惯 | 亲测、案例、数据、引文怎样进入正文 | 挪用样文的经历、数字、立场或成果 |
| 判断方式 | 怎样提出异议、给条件、承认不确定、从案例得出判断 | 每次复制原结论或制造虚假的锋利感 |
| 图文关系 | 图是证据、演示、数据解释、叙事还是情绪辅助 | 无图也强配图，编造没看过的截图细节 |

可以记典型短句帮助判断，但新稿不能拼接样文原句。长篇原文保留在用户指定的素材位置，分发技能只含空白模板，不含个人作品库。

## 每次起稿怎样用

1. 当前明确要求优先；其次是同体裁、有证据的个人文风，再其次是既有偏好和通用写法。事实、归属与素材边界始终保留。
2. 读档案摘要，再选少量与本次体裁、目的相关的原文片段核对，通常2—3篇就可开始；单条短推不必加载所有长文和全部分析产物。只有一篇时只作局部参考。
3. 记下本次采用的少量特征，如“先落在具体动作”“保留解释性冒号”“结尾回到尚未解决的卡点”。先按素材写，再用特征修表达，不先找可套原句。
4. 检查模仿是否只剩几个口头禅，段落是否仍有新信息；不能为了像作者添加天气、咖啡、对话、情绪或未经支持的成果。
5. 去AI味命中要结合作者证据和语义决定保留或修改。作者确实常用且含义清楚的并列、冒号、问句不因命中就删；明显重复仍要压缩，不用“这就是文风”掩盖缺内容。

只有需要保存文风档案或用户希望持续复用时，才将观察保存到其指定位置或本次输出目录；避免覆盖现有档案。记清这是用户要求、跨样文观察还是单篇暂定。后续用用户明确的文风反馈修正，不把“同意继续”当成整套风格已经验证。

## 冲突与缺资料

旧档案偏克制，用户这次要求更有悬念，就在真实材料内加强悬念；旧档案偏长句，用户只要紧凑短推，就优先紧凑完整。没有样文直接成稿，不先索要20篇作品。

要检查“像不像我”，需要有可比较的用户样文；缺少时只说明按已知偏好处理了哪些特征，不给虚假的相似度、人格画像或文风完成声明。
