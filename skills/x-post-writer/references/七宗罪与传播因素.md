# 七种动机与传播角度

七宗罪在这里是文化概念的创作借用，不是科学验证的七类用户画像。不要称读者为贪婪、懒惰或嫉妒的人，也不要把所有注意力都解释成这些动机。默认选一个主驱动，必要时一个辅助；文案仍须有事实、价值和合适对象。

## 动机怎样转为表达

| 名称 | 借用的读者愿望 | 可用表达 | 失效或越界 |
| --- | --- | --- | --- |
| 傲慢 | 能力感、自我认同、专业判断与认可 | 教会一个判断，呈现实际能力，让读者有选择依据 | “只有聪明人才懂”、贬低新手、虚构权威 |
| 嫉妒 | 看见差距后希望成长，向往可达到的能力 | 真实做法与可学步骤，把比较转成行动 | 虚构成功、收入、排名，用羞辱制造落后焦虑 |
| 愤怒 | 对低效、误导或不合理做法的不满 | 指出具体摩擦，解释原因，给解法或标准 | 找群体当敌人、辱骂个人、捏造丑闻 |
| 懒惰 | 降低理解和行动成本，减少重复劳动 | 清楚入口、复用步骤、避坑与起步方法 | 隐去必要投入，承诺一键成功、零努力获利 |
| 贪婪 | 希望得到更多可用价值，关心收益与成本 | 明确模板、能力、信息或有依据的收益，交代代价 | 虚构省时金额、收益率、名额和稀缺，承诺稳赚 |
| 暴食 | 原义涉及过量摄取；借用求知、新鲜感与探索欲 | 精选而完整的发现，解释价值，及时给答案 | 无边界清单、无限吊胃口，把囤积当行动 |
| 色欲 | 原义含性欲；一般创作只借审美、感官愉悦和美好场景向往 | 对真实画面、设计、体验和生活细节作具体表达 | 无关性暗示、物化人物、捏造效果、低俗围观 |

后两项是有意的创作类比，不声称信息摄取等于进食、审美等于性动机。不为套框架强迫严肃技术教程使用感官刺激。

## 先有价值，再选刺激点

现场课件提出视觉吸引、实用价值、容易上手和情绪共鸣。选角度时问：

1. **相关**：谁在经历这个问题？把行业词换成具体任务。
2. **承诺**：读完得到方法、解释、体验还是表达？至少一项清楚。
3. **依据**：什么真实过程、例子、画面或数据支撑？
4. **动机**：为什么值得现在停下？不靠语气更激烈代替。
5. **转述**：读者能用哪句话、哪个步骤或观察讲给别人？
6. **一致**：注意力是否接近希望长期服务的人？

好奇、惊讶、有依据的反差、具体性与阅读流畅度是表达工具，可以搭配主驱动。恐惧、损失厌恶和从众不是七宗罪清单的额外成员，也不是对所有读者有效的按钮。

## 选择示例

- 新手总卡在安装入口 → 懒惰：降低起步成本，写清关键动作，不许诺无需学习。
- 看别人把教程讲清楚 → 嫉妒：把能力差距变成观察方法，不编造对方涨粉或收入。
- 读完介绍仍不会操作 → 愤怒：指出表达与交付的缺口，给改进方法，不骂读者或同行。
- 刚学会也能解释一步 → 傲慢：建立能力感，不拿身份高低贬损他人。
- 同类案例提炼可用清单 → 贪婪，辅助暴食：给筛选过的信息收益，真正交付内容与边界。
- 设计或空间的细节令人向往 → 可借色欲的审美/感官映射，只写素材可见细节。

## 研究的范围

[Berger与Milkman，2012，What Makes Online Content Viral?](https://journals.sagepub.com/doi/10.1509/jmr.10.0353)研究新闻分享与情绪等因素，提示区别情绪方向与唤起程度，也考察惊奇、趣味和实用性。它不能直接给出中文X的推荐机制或爆款概率，也没有验证本技能的七宗罪映射。

这些只作为选题和表达的检查视角。出现愤怒、好奇或清单，不表示必然传播。效果需由用户实际发布后的反馈检验，技能不伪造验证结果。
